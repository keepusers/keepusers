# Tags & Selection Rules

## 推荐标签

- `AI-Agent`：Agent、自动化、工作流
- `Codex`：Codex、代码代理、开发环境
- `Local-AI`：本地模型、推理、训练
- `Voice-Audio`：声音克隆、TTS、RVC、音频处理
- `Video-Gen`：AI 视频、动画、数字人
- `Document-AI`：PDF/PPT/Word 解析、OCR、RAG
- `Automation`：桌面自动化、游戏自动化、脚本
- `DevTools`：开发工具、CLI、IDE、调试
- `Knowledge`：知识库、笔记、搜索、收藏
- `Productivity`：效率工具
- `Interesting`：暂时不好归类但值得保留

## 晨报入库标准

优先收藏满足至少一项的项目：
1. 能直接解决实际问题；
2. 可以本地部署或与 Codex 配合；
3. 有明确可复用的技术方案或 Idea；
4. 最近仍有维护、社区活跃；
5. 相比同类项目有明显差异化；
6. 适合作为后续学习、复刻、二次开发对象。

避免只因为 Star 高就收藏。优先记录“为什么对你有价值”。
