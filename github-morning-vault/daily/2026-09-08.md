## 1. oraios/serena

- GitHub: https://github.com/oraios/serena
- 一句话用途：给 Codex 等 Agent 增加基于 Language Server 的语义代码检索与编辑能力，相当于“Agent 的 IDE 层”。
- 为什么值得看：它不是再造一个 Coding Agent，而是补强现有 Agent 对大型代码库的符号级理解和编辑；项目成熟度高、社区活跃，适合与 codegraph/Graphify 的“结构地图”形成互补，而不是单纯再加一套 RAG。
- 适合怎么用：在一个真实 Python/TypeScript 项目中，让 Codex 分别使用普通文本搜索和 Serena 完成跨文件符号定位、引用追踪、函数级修改，比较上下文读取量和误改率。
- 本地部署/测试成本：**中**。需要配置 MCP/项目语言支持；无需本地大模型和高显存。
- 当前状态：**TRY**
- 下一步建议：选一个已有中型代码仓库做 3 个固定任务 A/B，记录定位调用数、读取源码量、修改正确率和 Token。
- 收藏库联动：**已收藏 / 值得跟进**

## 2. kenn-io/agentsview

- GitHub: https://github.com/kenn-io/agentsview
- 一句话用途：本地汇总 Codex、Claude Code 等 20+ Coding Agent 的 Session 搜索、分析、洞察和 Token 使用统计。
- 为什么值得看：收藏库已经开始做 Codex Harness Bake-off 和 Agent Efficiency Benchmark，但此前缺少统一的观测/数据层。AgentsView 更像“Agent 可观测性仪表盘”，能把凭感觉比较工具升级为基于历史 Session 和 Token 的量化比较。
- 适合怎么用：导入 Codex 历史 Session，先建立裸 Codex 的 Token、Session 长度、任务分布基线，再用于 LazyCodex/oh-my-codex/Caveman 等 A/B。
- 本地部署/测试成本：**低～中**。local-first，Go 后端 + Svelte/Tauri 桌面结构，不需要 GPU。
- 当前状态：**TRY**
- 下一步建议：先只导入 Codex 数据，确认隐私边界和统计准确性；若可靠，把它设为 Harness Bake-off 的统一计量层。
- 收藏库联动：**已收藏 / 值得跟进**

## 3. vercel-labs/skills

- GitHub: https://github.com/vercel-labs/skills
- 一句话用途：用 `npx skills` 统一发现、安装、使用、更新和删除 Agent Skills，支持 Codex 等大量 Agent。
- 为什么值得看：此前已收藏 local-skills-mcp 和 AAS Core，但还缺少一个轻量、通用的 Skill 包管理器。该项目支持项目级/全局安装、私有仓库、临时使用而不安装，以及跨 Agent 安装，适合把 Skill 管理从手工复制文件升级为可维护流程。
- 适合怎么用：把自己的 GitHub 项目评估 Skill 做成独立仓库，用 `npx skills add` 同时安装到 Codex 与其他 Agent；测试 `use`、`update`、`remove` 的完整生命周期。
- 本地部署/测试成本：**低**。主要需要 Node/npm，不需要 GPU；需注意项目存在匿名 telemetry，可通过 `DISABLE_TELEMETRY=1` 或 `DO_NOT_TRACK=1` 关闭。
- 当前状态：**TRY**
- 下一步建议：不要先装公共 Skill 大全；先用 1 个自建 Skill 验证“创建→安装→升级→回滚/删除”，再决定是否作为长期 Skill 包管理层。
- 收藏库联动：**已收藏 / 值得跟进**

## 4. K-Dense-AI/scientific-agent-skills

- GitHub: https://github.com/K-Dense-AI/scientific-agent-skills
- 一句话用途：给 Codex 等 Agent 提供材料科学、分子动力学、科学计算、数据分析等可复用科研 Skills。
- 为什么值得看：与此前 academic-research-skills-codex 偏“文献/论文流程”不同，这个项目更偏具体科学工具和数据库能力，覆盖材料科学、分子动力学、科学计算和可视化等方向，能补齐研究工作台的“分析执行层”。
- 适合怎么用：只挑 2～3 个与材料/MD/科学数据分析相关的 Skill，在历史研究数据或公开样例上验证结果可复现性、引用可靠性和依赖复杂度。
- 本地部署/测试成本：**低～中**。Skill 本身轻量，但具体科学工具/数据库可能有额外依赖；每个 Skill 的独立 license 需要单独检查。
- 当前状态：**REVIEW**
- 下一步建议：先审查材料科学、molecular dynamics、scientific visualization 三类 Skill，不整库安装；通过后再接入 Codex Research Workbench。
- 收藏库联动：**已收藏 / 值得跟进**
