### Comfy-Org/comfy-mcp — TRY
- 链接：https://github.com/Comfy-Org/comfy-mcp
- 用途：ComfyUI 官方组织下的本地 MCP server，让 Agent 运行、监控、检查和构建 ComfyUI workflow。
- 为什么值得看：已有 ComfyUI 收藏，但这个项目补齐 Codex/Agent 到 ComfyUI 的直接控制层，能把 AI Video Factory 从“脚本调用”升级为 MCP 工作流。
- 适合怎么用：Codex 生成/修改 workflow、提交异步任务、监控失败、收集输出。
- 部署/测试成本：中；需要已有/可运行的 ComfyUI 和 comfy-cli。
- 下一步建议：先用一个最小图像 workflow 验证 MCP → ComfyUI → 输出闭环，再扩展视频。
