## 1. korovin-aa97/talkthrough-mcp

- GitHub：https://github.com/korovin-aa97/talkthrough-mcp
- 一句话用途：把带讲解的屏幕录制转成可搜索的转录、关键帧、OCR 和精确时间证据，直接供 Codex 调试或生成 Bug Report。
- 为什么值得看：它解决的是“人如何把复杂 UI/运行时问题高质量交给 Agent”的输入瓶颈，不是再增加一个生成模型。录屏中的语音、画面、OCR 和时间轴被统一成证据包，适合复杂软件问题复现。
- 适合怎么用：录制 RVC/WebUI/本地软件异常 → talkthrough 本地索引 → Codex 读取证据 → GitHub MCP 创建 Issue 或直接修复；也可用于会议、产品演示和生产事故复盘。
- 本地部署/测试成本：中。需要本地媒体处理/转写依赖，但核心流程 local-first；先用 1–3 分钟问题录屏测试即可。
- 当前状态：TRY
- 下一步建议：固定一个真实 UI Bug，比较“文字描述给 Codex”与“talkthrough 证据包给 Codex”的定位时间、追问次数和修复成功率。
- 收藏库联动：已收藏 / 值得跟进

## 2. MarcusTseng/mcp-whisper

- GitHub：https://github.com/MarcusTseng/mcp-whisper
- 一句话用途：把 whisper.cpp 封装成 local-first MCP 转写服务，供 Codex 等 Agent 处理音频、URL、YouTube 或 RSS Podcast。
- 为什么值得看：现有收藏已有 mcp-listen、hearsay、Loqui，但该项目更偏“通用、可网络化部署的 Whisper MCP 基础服务”，并带 bearer auth、SSRF 防护和容器化设计。
- 适合怎么用：作为统一 STT 基础层，给视频知识化、会议转写、声音工作流和 Agent 语音输入复用同一个本地 whisper.cpp 服务。
- 本地部署/测试成本：中。需要 whisper.cpp 后端与模型；Docker/HTTP 部署比单机脚本更复杂，但复用价值更高。
- 当前状态：REVIEW
- 下一步建议：先与 mcp-listen/hearsay 做职责边界比较；只有能减少重复 Whisper 实例、统一模型和接口时再部署。
- 收藏库联动：已收藏 / 值得跟进

## 3. andreagrandi/mcp-wire

- GitHub：https://github.com/andreagrandi/mcp-wire
- 一句话用途：用一个 Go TUI 统一给 Codex、Claude Code、OpenCode 等安装和配置 MCP Server。
- 为什么值得看：Morning Vault 已经积累大量 MCP 项目，真正的问题开始从“找 MCP”转向“配置、迁移、卸载和跨 Agent 一致性”。mcp-wire 正好处在 MCP 生命周期治理层。
- 适合怎么用：建立测试机 MCP 配置清单，通过统一界面安装/卸载，再与 CC-Switch、Ratel Local 的职责分层：配置治理、上下文路由、Agent 配置分别处理。
- 本地部署/测试成本：低。Go 单体 CLI/TUI 思路轻量，测试不需要 GPU。
- 当前状态：REVIEW
- 下一步建议：选 3 个现有 MCP，在 Codex + 第二个 Agent 上测试安装、卸载、配置残留和回滚；确认不会破坏已有配置后再升 TRY。
- 收藏库联动：已收藏 / 值得跟进

## 4. LongNgn204/local-coding-agent

- GitHub：https://github.com/LongNgn204/local-coding-agent
- 一句话用途：把自己的电脑变成可由远端 AI/MCP 客户端访问的本地代码工作区，支持文件、命令、Git 和健康指标。
- 为什么值得看：它补的是“远端 AI → 自己电脑”的执行桥，Windows tray、权限恢复和指标面板对 Windows 主机更实际；但项目明确说明它不是 OS sandbox，因此安全边界必须优先验证。
- 适合怎么用：只在独立测试目录开放一个低权限 workspace，让远端 Agent 执行代码、测试和 Git 读取；不开放主目录、凭据目录和生产项目。
- 本地部署/测试成本：中。安装本身不重，但安全配置与 workspace 隔离成本较高。
- 当前状态：REVIEW
- 下一步建议：先审查 SECURITY.md 和权限模型，再用临时 Git 仓库测试 allowlist、命令执行、断线恢复和越界访问；通过后才考虑实际工作流。
- 收藏库联动：已收藏 / 值得跟进
