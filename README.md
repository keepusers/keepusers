# GitHub Morning Vault

用于沉淀每日 GitHub 晨报中的优质项目、可复用工具和 Idea，便于后续检索、回顾与实际部署。

## 目录

- `github-morning-vault/INDEX.md`：项目总索引，去重与快速检索入口
- `github-morning-vault/IDEAS.md`：从项目中提炼出的可执行 Idea
- `github-morning-vault/daily/`：按日期保存每日晨报精选
- `github-morning-vault/TAGS.md`：标签体系与筛选规则
- `github-morning-vault/TEMPLATE.md`：每日记录模板

## 联动规则

每日晨报发现 GitHub 项目后：
1. 先检查 `INDEX.md`，避免重复收藏；
2. 新项目写入当日 `daily/YYYY-MM-DD.md`；
3. 同步追加到 `INDEX.md`；
4. 有可复用思路时写入 `IDEAS.md`；
5. 晨报正文中标记“已收藏 / 已存在 / 值得跟进”。

目标不是堆链接，而是形成一个可持续回顾、筛选和转化的个人 GitHub 项目知识库。
